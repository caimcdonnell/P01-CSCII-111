# Color Helper

## Description

**version 1.0**

Helps determine between colors for those with color-blindness

## Developer

Cai Mcdonnell

## Example

To run the program, give the following commands:

```
Input Colors in RGB
```

Here is an example of the program running:

```
Please input your color code in RGB!
245 67 87
RED: 245 GREEN: 67 BLUE: 87
Your Color is Red!
Please input your color code in RGB!
```
